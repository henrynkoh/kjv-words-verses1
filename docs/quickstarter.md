# Quickstarter (10 minutes)

This quickstarter gets the dev server running. It does not require any Bible dataset to start the UI scaffold.

## 1. Prerequisites

- Node.js + npm installed
- A terminal with the project directory open

## 2. Install dependencies

```bash
npm install
```

## 3. Start the app

```bash
npm run dev
```

## 4. Open in your browser

Go to:

- `http://localhost:3000`

## 5. Next steps (when the verse/topic features are implemented)

- Add your transcript verse/topic lists to the importer input (via the project’s upcoming importer flow)
- Run the importer to generate the dataset used by the UI
- Verify “no redundancy or omissions” using the built-in validators (planned)
